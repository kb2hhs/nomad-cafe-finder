# UI仕様書

## 概要

Nomad Cafe FinderのUI/UX設計仕様を定義する。

## デザインコンセプト

### テーマ

**「都会のオアシス」** - ノマドワーカーが快適に作業できる場所を見つける安心感を表現

## 共通コンポーネント

### Header

```
┌──────────────────────────────────────────────────────────┐
│  ☕ Nomad Cafe   [🔍 検索...]         [♡ 3] [👤 Login] │
└──────────────────────────────────────────────────────────┘
```

- ロゴ（ホームへのリンク）
- 検索バー（結果・詳細ページで表示）
- お気に入り数バッジ（ログイン時）
- ログイン/ユーザーメニュー

### NomadScoreBadge

ノマドスコアを視覚的に表示するバッジ。

```
┌─────────┐
│ 💯 78pt │  ← 背景色がスコアに応じて変化
└─────────┘

80-100: 緑（おすすめ）
50-79:  黄（普通）
0-49:   赤（不向き）
```

### FeatureChips

Wi-Fi、電源、静かさを示すチップ。

```
[🌐 Wi-Fi] [⚡ 電源] [🔇 静か]
```

- 対応: 塗りつぶしスタイル
- 非対応: アウトラインスタイル（グレー）

## レスポンシブ対応

### ブレークポイント

| 名称 | 幅 | 対応デバイス |
|------|-----|-------------|
| sm | 640px | スマートフォン |
| md | 768px | タブレット縦 |
| lg | 1024px | タブレット横・小型PC |
| xl | 1280px | デスクトップ |

### モバイル対応

- 検索結果: リスト/地図の切り替えタブ
- フィルター: ボトムシート形式
- カフェ詳細: フルスクリーンモーダル

## インタラクション

### ローディング状態

- スケルトンスクリーンでコンテンツ領域を表示
- 検索中はプログレスインジケーター

### エラー状態

- トースト通知でエラーメッセージ表示
- リトライボタンを提供

### アニメーション

| 要素 | アニメーション |
|------|---------------|
| ページ遷移 | フェードイン (200ms) |
| カードホバー | 影の強調 (150ms) |
| モーダル表示 | スライドアップ (250ms) |
| マーカー選択 | バウンス |

## アクセシビリティ

- キーボードナビゲーション対応
- スクリーンリーダー対応（ARIA属性）
- コントラスト比 WCAG AA準拠
- フォーカスインジケーター明示
