# Nomad Cafe Finder 事業計画書

## 1. 事業概要 (Executive Summary)

**Nomad Cafe Finder** は、東京都内のリモートワーカーやノマドワーカーを対象とした、最適な作業場所（カフェ・コワーキングスペース）を瞬時に発見できる検索プラットフォームです。

従来のグルメサイトでは不十分だった「Wi-Fi速度」「電源の数」「静かさ」といった作業環境に関する情報を、AIとビッグデータ解析を用いて数値化（ノマドスコア）し、地図上で直感的に比較・検討できる体験を提供します。

初期ターゲットは東京23区のリモートワーカー層とし、広告モデルとアフィリエイトから収益化を開始。将来的にはプレミアム会員機能や店舗向け集客ソリューションを展開し、3年目で月商500万円、年間営業利益4,000万円を目指します。

## 2. ビジョン・ミッション

### ビジョン
**「働く場所の制約をなくし、誰もが自由に働ける社会へ」**
場所選びのストレスをゼロにし、クリエイティビティを最大化できる環境へのアクセスを民主化します。

### ミッション
**「最適な『座席』と『環境』を、最短でマッチングする」**
単なる店舗検索ではなく、その瞬間のニーズ（Web会議ができるか、集中できるか）に合致した環境を提供します。

## 4. 市場分析 (精緻化)

### 4.1 市場規模のフェルミ推定（ロジック詳細）

#### TAM (Total Addressable Market) - 日本全国

**前提条件・出典:**
1.  **労働力人口**: 6,900万人 (総務省統計局 2024年)
2.  **リモートワーク実施率**: 24.6% (国土交通省「令和6年度 テレワーク人口実態調査」[1])
3.  **カフェ作業率**: 15% (推計値: カフェ利用頻度「週1回以上」層の割合等より算出)
4.  **年間支出**: ¥36,000 (単価¥500 × 72回/年 [月6回])

```math
\text{TAM} = 6,900\text{万人} \times 24.6\% \times 15\% \times ¥36,000 \approx \textbf{916億円}
```

> **ロジックの根拠**:
> コロナ禍を経てリモートワーク実施率は首都圏で30%超、全国でも約25%で定着しています。フリーランス人口の増加（1,300万人超 [2]）も追い風となり、カフェを作業場とする「サードプレイス需要」は底堅いと判断しました。

#### SAM (Serviceable Available Market) - 首都圏

**前提条件:**
1.  **首都圏労働力人口**: 2,100万人
2.  **首都圏リモートワーク実施率**: 36.2% (国土交通省調査・首都圏雇用型 [1])
3.  **カフェ作業率**: 20% (都市部はカフェ密度が高く、利用習慣が定着していると仮定)

```math
\text{SAM} = 2,100\text{万人} \times 36.2\% \times 20\% \approx \textbf{152万人 (ユーザー数ベース)}
```

#### SOM (Serviceable Obtainable Market) - 東京23区・3年後

**前提条件:**
1.  **23区労働力人口**: 約700万人
2.  **ターゲットセグメント**: IT系・フリーランス比率が高いエリア特性を考慮し、リモート率40%と仮定。
3.  **市場シェア目標**: 競合（電源カフェ等）からのスイッチングと新規開拓でシェア10%強を目指す。

```math
\text{SOM} = 700\text{万人} \times 40\% \times 25\% (\text{カフェ利用}) \times 43\% (\text{認知・利用}) \approx \textbf{30万人 (MAU目標)}
```

> **実現可能性**:
> 競合トップの「電源カフェ」が月間15万UUであることを考慮すると、30万MAUは野心的ですが、市場全体のパイ拡大（コワーキング市場予測 CAGR 15% [3]）とAIによる差別化を考慮すれば、3年目での達成は十分可能な範囲です。

### 8.2 バイラル係数 (K-Factor) 戦略

#### K-Factor計算

```
K = i × c
i (招待数): 平均招待送信数 = 2.0人/ユーザー
c (CVR): 招待からの登録率 = 15%
K = 2.0 × 0.15 = 0.30

目標: K > 0.5 (オーガニック成長加速)
```

#### バイラル施策

| 施策 | 内容 | 期待効果 |
|:---|:---|:---|
| **シェア機能** | カフェ情報をSNSシェアでポイント付与 | i +0.5 |
| **招待インセンティブ** | 友達招待で両者に100ポイント | c +5% |
| **レビュー投稿報酬** | 写真付きレビューで200ポイント | UGC増加 |
| **ランキング機能** | 週間投稿ランキングでバッジ付与 | エンゲージメント向上 |

#### 改善後K-Factor目標

```
改善後K = 2.5 × 0.20 = 0.50
→ 自然増加率50%達成で広告費削減可能
```

## 14. 結論

Nomad Cafe Finderは、リモートワーク定着という不可逆な社会トレンドに乗った、高い成長ポテンシャルを持つサービスです。

**本計画のハイライト:**

1. **市場機会**: 電源カフェ（月間15万UU）を上回る市場リーダーを目指す
2. **競合優位性**: AIスコアリング × モダンUX × データ網羅性の三位一体
3. **低リスク**: 初期投資6万円、損益分岐点MAU 640人と極めて低い
4. **高収益性**: 3年目営業利益率66%、キャッシュ5,000万円超
5. **明確な出口**: 3〜6億円での売却オプション、またはキャッシュカウ継続

技術的差別化とリーンな運営体制により、低コストで参入しつつ、高収益なプラットフォームへ成長させることが可能です。
